HOLLOW BELL — a timing-puzzle game. You are a bellwright in a half-drowned bronze foundry: place resonator bells, strike them, and two expanding rings must cross exactly on a seal to shatter it. Eight chambers, Mutes that eat your bells, pillars that reflect rings, a Conductor that slows them, the Silent Cantor waiting in chamber 8 with its three dampener arms, and an endless mode for score chasing. Pure vanilla JS + canvas, no network, no build step.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
